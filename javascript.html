JavaScript Notes

A simple and interactive reference

This page collects core JavaScript concepts in a format that is easy to browse, search, and understand. Each card uses simple beginner-friendly explanations and small code examples.

Filter by category

Variables

A variable stores a value that can be used later.

let name = "Nonso";
console.log(name);

What this does

This creates a variable called name, stores the text "Nonso" inside it, and then prints that value to the console.

Result

Nonso

Strings

A string is text wrapped in quotes.

let message = "Hello World";
console.log(message);

What this does

This stores text inside a variable called message and prints that text to the console.

Result

Hello World

Numbers

Numbers are used for values you want to calculate with.

let score = 25;
console.log(score + 5);

What this does

This creates a number variable called score, adds 5 to it, and prints the new value.

Result

30

Booleans

A boolean only has two possible values: true or false.

let isLoggedIn = true;
console.log(isLoggedIn);

What this does

This saves the value true in a variable and prints it. Booleans are often used in conditions.

Result

true

if / else

if / else lets your code make decisions.

let score = 62;

if (score >= 50) {
    console.log("Pass");
} else {
    console.log("Try again");
}

What this does

This checks whether score is greater than or equal to 50. Since the score is 62, the first block runs.

Result

Pass

Comparison Operators

Comparison operators compare values and return true or false.

console.log(10 > 5);
console.log(4 === 4);

What this does

The first line checks whether 10 is greater than 5. The second line checks whether 4 is exactly equal to 4.

Result

true
true

for Loop

A for loop repeats code a set number of times.

for (let i = 0; i < 5; i++) {
    console.log(i);
}

What this does

This starts at 0 and keeps running until the value is no longer less than 5. The value of i changes on each loop.

Result

0
1
2
3
4

while Loop

A while loop keeps running while a condition stays true.

let count = 3;

while (count > 0) {
    console.log(count);
    count--;
}

What this does

This keeps printing the value of count while it is greater than 0. After each loop, the value goes down by 1.

Result

3
2
1

Functions

A function is a reusable block of code.

function greet() {
    console.log("Hello");
}

greet();

What this does

This creates a function named greet. The function does nothing until it is called. When greet() runs, it prints a message.

Result

Hello

Parameters

Parameters let a function accept input values.

function greetUser(name) {
    console.log("Hello " + name);
}

greetUser("Nonso");

What this does

This function accepts one input called name. When the function runs, it joins "Hello " with the value passed in.

Result

Hello Nonso

Return

return sends a value back from a function.

function add(a, b) {
    return a + b;
}

console.log(add(2, 3));

What this does

This function adds two values and sends the answer back. The returned value is then printed to the console.

Result

5

Arrays

An array stores multiple values in one variable.

let colors = ["red", "blue", "green"];
console.log(colors[1]);

What this does

This creates an array with three values. Arrays use index numbers, and index 1 points to the second item.

Result

blue

Objects

An object stores related data using keys and values.

let car = {
    make: "Honda",
    year: 2020
};

console.log(car.make);

What this does

This creates an object called car with two properties. The last line prints the value stored in the make property.

Result

Honda

getElementById

This method selects one element by its id.

const heading = document.getElementById("title");
heading.textContent = "New title";

What this does

This finds the element with the id title and changes the text inside it.

Result on page

The selected element now shows:
New title

textContent and innerHTML

These are two common ways to update content on the page.

element.textContent = "New text";
element.innerHTML = "<strong>Bold text</strong>";

What this does

textContent adds plain text only. innerHTML can add HTML tags and structure too.

Result on page

textContent → New text
innerHTML → Bold text (shown in bold)

createElement and appendChild

These methods let you create and add new elements with JavaScript.

const item = document.createElement("li");
item.textContent = "New item";
list.appendChild(item);

What this does

This creates a new list item, gives it text, and adds it to an existing list on the page.

Result on page

A new <li> appears inside the list:
New item

Click Events

A click event runs code when the user clicks something.

button.addEventListener("click", function () {
    console.log("Button clicked");
});

What this does

This waits for the user to click a button. When the click happens, the function runs and logs a message.

Result

Button clicked

Input and Submit Events

These events help you work with forms and typed input.

form.addEventListener("submit", function (event) {
    event.preventDefault();
    console.log("Form handled with JavaScript");
});

What this does

This listens for a form submission, stops the page from refreshing, and lets JavaScript handle the form instead.

Result

Form handled with JavaScript
